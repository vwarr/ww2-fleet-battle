# Normandy P1: scenario plumbing, nations and the setup toggle

Plan: [docs/NORMANDY_PLAN.md](../NORMANDY_PLAN.md) P1.

## What changed
- `js/scenario.js` (new, after core.js): `WW.scenarios` {pacific, normandy}, `WW.scn()`, `WW.sides()`, `WW.perSide(v)`,
  `WW.sideSpec(n)` (start zone, spawn heading, home edge), `WW.setScenario(id)` (also sets `WW.ENEMY` and
  `ROUND_TIMEOUT`), `?scn=normandy`. Pacific's side specs are the literals main.js used before.
- `js/normandy.js` (new): the Normandy hooks: `composition` (a placeholder bombardment group + 3 S-boats),
  `updateGame` (time limit only, 1000 s), `admirals` (Hall / Bryant; Kraiss / Hoffmann), `fleetSides`, `patrol: false`.
- `core.js`: `WW.enemyOf` reads the `WW.ENEMY` table; `NATIONS.GER`; `WW.FLAGS` (USN, RN, FNFL); GER S-boat torpedoes.
- `main.js`: `SIDE` → `WW.sideSpec`; composition loops, `deadline`, per-side clocks over `WW.sides()`;
  `scn.composition`, `scn.updateGame` hooks; spawn passes `heading`, `cls`, `flag` from the composition.
- `ships.js`: `ship.flag` (default = nation), spawn heading from the side spec.
- `endgame.js`: `homeX` from the side spec's home edge; `scn.escapes === false` turns escapes off; lull / night
  checks over the scenario's two sides. `ai_endgame.js` escape edge from `homeX`.
- `fleet_cmd.js`, `intel.js`, `admirals.js`, `ship_fires.js`, `air_staff.js`, `air_patrol.js`, `air_aces.js`,
  `fleet_formation.js`, `ai_charge.js`, `air_flyingboats.js`, `night_ops.js`, `air_search.js`: side loops and
  per-side tables over `WW.sides()` / `WW.perSide()` (the sector search's "enemy half" from the home edges).
- GER entries: doctrine (`fleet_groups.js`), ship palette (`models.js`, plus RN / FNFL), crew uniforms
  (`models_crew.js`), the S-boat class (`ship_classes.js` `sboot`, Elco model kit for now).
- `island_base.js`: `scn.base` ('none' in Normandy) fixes the owner with no WW.rand roll.
- `ui.js`: Pacific | Normandy toggle in the setup panel (new map + fleets, URL keeps `?scn=`); side rows, counts and
  colours follow the scenario's sides; the Base button hides in Normandy.
- Tests: `tests/nation_lint.js` (new), `tests/trace_dump.js` (new: bit-identical trace baselines across commits),
  `tests/normandy_probe.js` (new: seeded Normandy rounds, NaN / page errors / replay check).
