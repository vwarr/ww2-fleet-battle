# Normandy P3: one list of land targets

Plan: [docs/NORMANDY_PLAN.md](../NORMANDY_PLAN.md) P3.

## What changed
- `js/land_sites.js` (new, before combat.js): `WW.landSites.register(provider)`; hooks `impact`, `hitTest`,
  `scan`, `shooters`, `roofAt`, `groundAt`, `bombardRange` (+ `owns`). Providers run in registration (load) order;
  `shooters` returns the ships array itself when no provider adds a unit.
- `island_base.js` registers itself as the first provider (impact, roofAt, scan and AA pits only while a base
  exists, bombardRange via base_ai.js for `t.isBase`).
- The call sites loop over the providers: `combat.js` landShell (shell impacts), `combat_weapons.js` updateBomb,
  `combat_aa.js` (AA shooters), `intel.js` scan, `aircraft.js` (roof floor), `ai_surface.js` prefRange
  (`t.isBase || t.isLand`). `air_staff.js` (the enemy airfield as a strike objective), `camera_scenes.js` and
  `ui.js` stay island-base specific (an airfield, not a generic land target).
- `combat.js findHit`: after the ships, the providers' `hitTest` (only when some provider has one: Pacific skips
  it). The preferred target is never a land unit on the ship path (`!prefer.isLand`).
- `combat.js fireShell`: aims at `target.y || 0` (casemates on the bluff top); for ships the arithmetic is
  unchanged (`+ 0`).
